Intro

I'm a penetration testing intern at LRQA in Birmingham, UK, and a BSc Applied Cybersecurity student at the SANS Technology Institute. My work centres on offensive security, particularly penetration testing, cryptography, and digital forensics.

On LRQA's Penetration Testing team I take part in mobile, web application, API, and infrastructure assessments from kick-off through delivery, and I am building a benchmark for AI-driven web application testing tools.

This site collects my competition writeups, research projects, and CV.

AI-Driven Penetration Testing

At LRQA I am developing a benchmark methodology for evaluating web application penetration testing. It uses reported findings and recorded requests to assess coverage, verification, conduct, and testing quality, whether testing is performed by a person or an automated product.{{ with site.GetPage "/posts/benchmarking-ai-human-web-penetration-testing" }} Read the research introduction →{{ end }}

VKB Sync

A Python tool that uses the PlexTrac API to keep LRQA's library of vulnerability findings synchronised across its Singapore, United Kingdom, and United States instances. It runs at no operating cost on scheduled GitHub Actions workflows and has run daily in production since deployment.
